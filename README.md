# Tartil

## A Comprehensive Digital Journey with the Quran and Daily Worship

Developed Tartil, a mobile application that integrates Quran reading, Hadith, daily supplications (morning, evening, sleep, and wake-up), and Tasbeeh. Tartil enhances the spiritual experience with the following features:

Prayer Timings: Displays accurate prayer times based on real-time API integration.
Quran Recitation: Complete Quran with the ability to listen and navigate through verses.
Daily Supplications and Tasbeeh: Provides structured morning, evening, and daily supplications, with additional sections for tasbeeh.
Daily Reminders: Custom notifications for important prayers and daily supplications.
Personal Profile: Track personal spiritual progress with a dedicated user profile.
Technologies Used:

HTTP API: To fetch Quran content, Hadith, supplications, and prayer times.
Bloc State Management: Ensures smooth and responsive user experience.
Animations: Implemented to enhance user interaction and engagement.
Clean Architecture: Organized codebase ensuring scalability and ease of future development.
MVVM Pattern: Ensures code reusability and clear separation of concerns.
